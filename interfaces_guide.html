Guide des Interfaces

Programmation Orientée Objet & JavaScript

🔍 Interface en Programmation Orientée Objet

Définition : Une interface est un contrat qui définit un ensemble de méthodes qu'une classe doit obligatoirement implémenter, sans spécifier leur implémentation concrète.

Schéma Conceptuel POO

Interface Vehicule
+ demarrer()
+ arreter()
+ getVitesse()
⬇
Classe Voiture
implements Vehicule
+ demarrer() { ... }
+ arreter() { ... }
+ getVitesse() { ... }
Classe Moto
implements Vehicule
+ demarrer() { ... }
+ arreter() { ... }
+ getVitesse() { ... }

📋 Caractéristiques principales

  • Contrat obligatoire : Définit les signatures des méthodes sans implémentation
  • Polymorphisme : Permet d'utiliser différentes classes via la même interface
  • Héritage multiple : Une classe peut implémenter plusieurs interfaces
  • Découplage : Sépare la définition de l'implémentation
  • Standardisation : Impose une structure commune

💻 Exemple en Java

interface Vehicule { void demarrer(); void arreter(); int getVitesse(); } class Voiture implements Vehicule { private int vitesse = 0; public void demarrer() { System.out.println("Voiture démarrée"); } public void arreter() { vitesse = 0; System.out.println("Voiture arrêtée"); } public int getVitesse() { return vitesse; } }

🌐 Interface en JavaScript

Contexte : JavaScript natif ne possède pas d'interfaces comme Java ou C#, mais le concept peut être simulé de plusieurs façons.

1️⃣ Avec TypeScript (Recommandé)

interface Utilisateur { nom: string; age: number; seConnecter(): void; } class Admin implements Utilisateur { nom: string; age: number; constructor(nom: string, age: number) { this.nom = nom; this.age = age; } seConnecter(): void { console.log(`${this.nom} est connecté`); } }

2️⃣ JavaScript Pur (Convention)

// "Interface" par convention const InterfaceVehicule = { demarrer: function() { throw new Error("Méthode non implémentée"); }, arreter: function() { throw new Error("Méthode non implémentée"); } }; // Classe qui "implémente" l'interface class Moto { demarrer() { console.log("Moto démarrée"); } arreter() { console.log("Moto arrêtée"); } }

3️⃣ Avec Classes Abstraites

class VehiculeInterface { demarrer() { throw new Error("Méthode abstraite non implémentée"); } arreter() { throw new Error("Méthode abstraite non implémentée"); } } class Camion extends VehiculeInterface { demarrer() { console.log("Camion démarré"); } arreter() { console.log("Camion arrêté"); } }

🎯 Avantages des Interfaces

✨ Bénéfices

  • Cohérence : Garantit une structure uniforme entre les classes
  • Maintenabilité : Facilite les modifications et extensions
  • Testabilité : Permet le mocking et les tests unitaires
  • Documentation : Sert de documentation vivante du code
  • Polymorphisme : Utilisation transparente de différentes implémentations
  • Découplage : Réduit les dépendances entre composants

Exemple d'Usage Polymorphe

// Fonction qui accepte n'importe quel véhicule function demarrerVehicule(vehicule: Vehicule) { vehicule.demarrer(); // Fonctionne avec Voiture, Moto, Camion... } const voiture = new Voiture(); const moto = new Moto(); demarrerVehicule(voiture); // "Voiture démarrée" demarrerVehicule(moto); // "Moto démarrée"

📚 Résumé

L'interface est un pilier fondamental de la POO qui permet de définir des contrats clairs entre les composants d'une application.

En POO classique, elle est native et puissante. En JavaScript, bien qu'elle ne soit pas native, elle peut être simulée efficacement, surtout avec TypeScript qui offre une expérience proche des langages typés.

Recommandation : Utilisez TypeScript pour les projets JavaScript nécessitant des interfaces robustes.
