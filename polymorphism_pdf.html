Le Polymorphisme

Programmation Orientée Objet & JavaScript

📖 Définition

Le polymorphisme est un concept fondamental de la POO qui permet à des objets de différentes classes de répondre à la même interface ou méthode, mais de manière spécifique à leur type.

Étymologie : Du grec "poly" (plusieurs) et "morphe" (forme) = "plusieurs formes"

🎯 À quoi sert le polymorphisme ?

Le polymorphisme permet d'écrire du code plus flexible et réutilisable en traitant des objets différents de manière uniforme, tant qu'ils partagent une interface commune.

Principe clé : Une même fonction peut travailler avec différents types d'objets sans connaître leur type exact, tant qu'ils implémentent les mêmes méthodes.

💡 Exemples pratiques en JavaScript

Exemple 1 : Polymorphisme avec héritage - Les Animaux
Classes de base et dérivées
// Classe de base
class Animal {
    constructor(nom) {
        this.nom = nom;
    }
    
    // Méthode que chaque animal redéfinira
    faireDuBruit() {
        return "L'animal fait un bruit";
    }
    
    sePresenter() {
        return `Je suis ${this.nom} et ${this.faireDuBruit()}`;
    }
}

// Classes dérivées
class Chien extends Animal {
    faireDuBruit() {
        return "je fais Wouf wouf !";
    }
}

class Chat extends Animal {
    faireDuBruit() {
        return "je fais Miaou !";
    }
}

class Vache extends Animal {
    faireDuBruit() {
        return "je fais Meuh !";
    }
}
Utilisation polymorphe
// Création d'un tableau d'animaux différents
const animaux = [
    new Chien("Rex"),
    new Chat("Whiskers"), 
    new Vache("Marguerite")
];

// POLYMORPHISME EN ACTION
animaux.forEach(animal => {
    console.log(animal.sePresenter());
    // Chaque animal utilise SA propre version de faireDuBruit()
});

// Résultat :
// Je suis Rex et je fais Wouf wouf !
// Je suis Whiskers et je fais Miaou !
// Je suis Marguerite et je fais Meuh !
Exemple 2 : Formes géométriques
Classes des formes
class Forme {
    calculerAire() {
        throw new Error("Méthode à implémenter");
    }
    
    calculerPerimetre() {
        throw new Error("Méthode à implémenter");
    }
}

class Rectangle extends Forme {
    constructor(largeur, hauteur) {
        super();
        this.largeur = largeur;
        this.hauteur = hauteur;
    }
    
    calculerAire() {
        return this.largeur * this.hauteur;
    }
    
    calculerPerimetre() {
        return 2 * (this.largeur + this.hauteur);
    }
}

class Cercle extends Forme {
    constructor(rayon) {
        super();
        this.rayon = rayon;
    }
    
    calculerAire() {
        return Math.PI * this.rayon * this.rayon;
    }
    
    calculerPerimetre() {
        return 2 * Math.PI * this.rayon;
    }
}
Fonction polymorphe
// Cette fonction peut travailler avec N'IMPORTE quelle forme
function afficherInfosForme(forme) {
    console.log(`Aire: ${forme.calculerAire().toFixed(2)}`);
    console.log(`Périmètre: ${forme.calculerPerimetre().toFixed(2)}`);
}

// Utilisation
const formes = [
    new Rectangle(5, 3),
    new Cercle(4)
];

formes.forEach(afficherInfosForme);
// Même fonction, comportements différents !
Exemple 3 : Duck Typing (Sans héritage)
// Classes sans relation d'héritage
class Voiture {
    demarrer() {
        return "La voiture démarre avec le moteur";
    }
}

class Velo {
    demarrer() {
        return "Le vélo démarre en pédalant";
    }
}

class Avion {
    demarrer() {
        return "L'avion démarre ses réacteurs";
    }
}

// Fonction qui fonctionne avec tout objet ayant une méthode demarrer()
function lancerVehicule(vehicule) {
    console.log(vehicule.demarrer());
}

// Utilisation
const vehicules = [new Voiture(), new Velo(), new Avion()];
vehicules.forEach(lancerVehicule);

Duck Typing : "Si ça marche comme un canard et ça fait coin-coin comme un canard, c'est un canard" - Pas besoin d'héritage, juste la même interface !

✨ Avantages du polymorphisme

🔄 Flexibilité

Traiter différents types d'objets de manière uniforme sans connaître leur type exact.

📈 Extensibilité

Ajouter de nouveaux types sans modifier le code existant qui utilise ces objets.

🔧 Maintenance

Les modifications se font localement dans chaque classe, sans affecter le reste du code.

♻️ Réutilisabilité

Une même fonction peut travailler avec tous les objets respectant une interface commune.

🎯 Abstraction

Se concentrer sur "quoi faire" plutôt que sur "comment le faire" pour chaque type.

📝 Code propre

Réduction de la duplication de code et amélioration de la lisibilité.

🔍 Types de polymorphisme en JavaScript

1. Polymorphisme par héritage

Les classes enfants redéfinissent les méthodes de la classe parent (override). Chaque classe a sa propre implémentation de la méthode.

2. Duck Typing

Si deux objets ont les mêmes méthodes, ils peuvent être utilisés de manière interchangeable, même sans relation d'héritage. C'est une spécificité des langages dynamiques comme JavaScript.

🎯 Résumé

Le polymorphisme est un outil puissant qui rend votre code :

  • Plus modulaire : Chaque classe gère sa propre logique
  • Plus maintenable : Modifications localisées
  • Plus évolutif : Ajout facile de nouveaux types
  • Plus réutilisable : Fonctions génériques

Le polymorphisme permet à différents objets de répondre à la même interface selon leur propre logique.
