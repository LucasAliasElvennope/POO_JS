# POO : Comprendre ce qu'est une Classe

En Programmation Orientée Objet (POO), une **classe** est un **modèle, un plan ou un blueprint** qui définit la structure et le comportement des objets. C'est une sorte de "fabrique" à objets.

Pensez à une classe comme un **plan de conception pour des entités similaires**. Elle décrit les caractéristiques communes (les **attributs** ou propriétés) et les actions que ces entités peuvent effectuer (les **méthodes**).

Par exemple, si vous voulez modéliser des personnes dans un programme, vous pourriez créer une **classe `Personne`**. Cette classe définirait :
* **Attributs :** `nom`, `âge`, `adresse`, `profession`.
* **Méthodes :** `marcher()`, `parler()`, `manger()`, `travailler()`.

Une fois que vous avez défini la classe `Personne`, vous pouvez créer (instancier) plusieurs **objets** (des instances) de cette classe, chacun ayant ses propres valeurs pour les attributs (par exemple, une personne nommée "Alice" de 30 ans, une autre nommée "Bob" de 25 ans, etc.), mais tous partageant les mêmes méthodes.

Les classes sont essentielles en POO car elles permettent de :
* **Organiser le code :** Elles regroupent les données et le comportement liés à une entité.
* **Réutiliser le code :** Une fois une classe définie, elle peut être utilisée pour créer un nombre illimité d'objets.
* **Modéliser le monde réel :** Elles offrent un moyen intuitif de représenter des concepts et des entités complexes.
